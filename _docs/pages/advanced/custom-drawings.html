Advanced Tutorial: Custom Drawings

Drawings can be very powerful in DCS missions.
They can guide players towards the right objectives or warn them of dangers ahead.
In Spearhead, we provide an easy way to manage and update these drawings dynamically as the mission progresses.

How to

Adding a custom drawing is easy.
Simply create the drawing and then name it according to the following convention:
DRAWING_[a]:[b]_[FreeForm]
Where:

  • [a] is the stage number at which the drawing should appear.
  • [b] is the stage number at which the drawing should be removed again.
  • [FreeForm] is any name you want to make it unique or findables.

The custom drawings need to be in the "Author" layer of the mission editor to be managed by Spearhead. This is due to other layers being visible by default and cannot be as easily removed when not needed. The author layer is not visible by default in multiplayer, making it perfect for this use case.
